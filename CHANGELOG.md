# Изменения

Формат по [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [0.1.1] - 2026-11-13

Исправления ложных срабатываний и защиты приложений.

Исправлено:

- Ложное «мимо VPN выйти можно» у VPN с поддержкой IPv6: проверочные сайты отвечали
  IPv6-адресом, а запрос в обход туннеля шёл по IPv4, и адреса не совпадали. Теперь
  проверка внешнего адреса идёт только по IPv4, IPv6 проверяется отдельно.
- Ложное «VPN-клиент не отвечает», когда локальный прокси держит процесс другого
  пользователя или системное расширение: его сокеты не видны, теперь к порту делается
  пробное подключение.
- Виджеты и другие расширения (.appex) с соединениями напрямую больше не считаются
  VPN-клиентом: раньше их трафик мимо VPN не показывался как утечка.
- Программа в режиме «Закрыть», которая не закрылась за 3 секунды (например, спрашивает
  про несохранённый документ), теперь замораживается, а не остаётся в сети.
- Обрыв VPN, случившийся во время идущей проверки, больше не ждёт запасного таймера.
- Замороженные программы отпускаются и при завершении VPN Lens по сигналу (`kill`).
- Отчёт текстом без VPN больше не пишет, что все соединения идут через VPN.
- Раздел «Приложения» в открытом окне обновляется раз в 3 секунды, а не раз в 10.
- «Адрес зависит от сайта» в обзоре не показывается из-за адреса запроса в обход туннеля.
- Консольная утилита спрашивает ip.nic.ru только с `--regional`, как и приложение.

## [0.1.0] - 2026-11-05

Первая публичная версия.

- Меню в строке меню: через VPN ли ходит активная программа, какой адрес видят сайты,
  что делать с программой, если VPN отключится, и одна строка про остальные программы.
- Окно с разделами «Обзор», «Приложения», «Защита», «Проверки», «История», «Сеть»
  и «Настройки».
- Проверки утечек: обход туннеля через физический интерфейс, UDP (как у WebRTC), IPv6,
  DNS, разные адреса для разных сайтов. Вердикт «мимо VPN» только по замеру.
- Распознавание VPN-клиента, служебных адресов туннеля (198.18.0.0/15) и упавшего
  клиента, который оставил системный прокси.
- Защита приложений: заморозка или закрытие выбранных программ, когда VPN отключился,
  и возобновление, когда вернулся. Выбор запоминается для каждой программы.
- Проверка kill switch и внешний DNS-тест через bash.ws, оба только по кнопке.
- Уведомления, история событий, отчёт текстом для поддержки VPN.
- Запуск при входе в систему, горячая клавиша для меню, экран первого запуска.
- Интерфейс на русском и английском: по умолчанию как в системе, в настройках можно
  выбрать язык отдельно.
- Региональный проверочный сайт (ip.nic.ru) - отдельная настройка, по умолчанию выключен.
- Консольная утилита `vpnlens` с тем же ядром.
- Cask для Homebrew, страница на GitHub Pages, шаблоны issue, CONTRIBUTING и SECURITY.
