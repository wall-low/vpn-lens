# Безопасность / Security

## Как сообщить об уязвимости

Если вы нашли уязвимость, не создавайте публичный issue. Напишите через
[GitHub Security Advisories](https://github.com/wall-low/vpn-lens/security/advisories/new):
это закрытый канал, сообщение увидит только автор.

Что пригодится в сообщении: версия VPN Lens и macOS, шаги воспроизведения, что именно
может сделать злоумышленник. Постараюсь ответить в течение недели.

Особенно интересны: способ заставить VPN Lens отпустить защищённые программы, пока VPN
отключён; утечка данных о программах или соединениях за пределы Mac; выполнение кода
через данные, которые VPN Lens получает от проверочных сайтов.

## Reporting a vulnerability

Please don't open a public issue. Report it through
[GitHub Security Advisories](https://github.com/wall-low/vpn-lens/security/advisories/new),
which is private to the project maintainers. Include the VPN Lens and macOS versions, steps to reproduce
and what an attacker could do. I'll try to reply within a week.

## Поддерживаемые версии / Supported versions

Исправления выходят для последней версии. / Fixes go into the latest release.
